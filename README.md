
## 🎵 Glory Music Player

A web-based music player inspired by **Yo Yo Honey Singh's _Glory_ album**, built with vanilla HTML, CSS, and JavaScript.

The project focuses on a clean interface, smooth playback controls, and a simple album-based listening experience.

## Features

-   Play, pause, previous, and next controls
-   Album-based tracklist
-   Dynamic track information
-   Album artwork for tracks
-   HTML5 audio playback
-   Responsive layout
-   Clean and minimal UI

## 🚀Live Demo

🎧 **[Open Glory Music Player](https://vikasprajapati3.github.io/music-player/)**

## Tech Stack

-   **HTML5** — Semantic structure
-   **CSS3** — Layout, styling, and responsiveness
-   **JavaScript** — Player logic and interactions
-   **HTML5 Audio API** — Audio playback
